# Contract: Export File Formats

**Feature**: 003-sports-tracking-tier | **Contract Type**: External (User-facing file output)

---

## Overview

Sports Pro users can export single or multiple game sessions to PDF, CSV, or JSON. This contract defines the structure and content of each format.

---

## PDF Export

**File naming**: `SkorKeeper_Export_{YYYYMMDD_HHMMSS}.pdf`
**MIME type**: `application/pdf`
**Generation**: `pdf` package (pure Dart); shared via `share_plus`

### Document Structure (single-game report)

```
┌────────────────────────────────────────────────────────┐
│  SkorKeeper                        [sport icon]  [date] │
│  ─────────────────────────────────────────────────────  │
│  BASEBALL — GAME REPORT                                  │
│  Home Team: Wildcats    Away Team: Eagles               │
│  Date: August 8, 2026   Format: 9-Inning                │
├────────────────────────────────────────────────────────┤
│  FINAL SCORE                                            │
│  Wildcats  7     Eagles  4                              │
├────────────────────────────────────────────────────────┤
│  BOX SCORE                                              │
│  ┌──────┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐            │
│  │      │ 1│ 2│ 3│ 4│ 5│ 6│ 7│ 8│ 9│ R│ H│            │
│  ├──────┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤            │
│  │Wild. │ 0│ 2│ 0│ 1│ 0│ 3│ 0│ 0│ 1│ 7│10│            │
│  │Eagle │ 0│ 0│ 2│ 0│ 1│ 0│ 1│ 0│ 0│ 4│ 8│            │
│  └──────┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘            │
├────────────────────────────────────────────────────────┤
│  STATISTICS                                              │
│  [Sport-specific stats table]                           │
├────────────────────────────────────────────────────────┤
│  GAME NOTES                                              │
│  [User-entered notes, if any]                           │
├────────────────────────────────────────────────────────┤
│  [Generated by SkorKeeper — skorkeeper.app]             │
└────────────────────────────────────────────────────────┘
```

### Multi-game report (bulk export)
- One page per game
- Summary cover page listing all included games with final scores

### Required PDF fields per sport

| Sport | Stats Section Includes |
|---|---|
| Baseball | Box score (inning-by-inning), R/H/E totals, BA, ERA |
| Basketball | Points per quarter, FG%, 3P%, FT%, total points |
| Football | Points per quarter, total yards, TDs, 1st downs |
| Soccer | Goals per half, possession %, goal timeline (in-depth: scorer names) |
| Tennis | Sets won, games per set, tiebreak results |
| Volleyball | Points per set, sets won, serving statistics |
| Hockey | Goals per period, assists, penalty log |
| Lacrosse | Goals, assists, ground balls, clears |

## CSV Export

**File naming**: `SkorKeeper_Export_{YYYYMMDD_HHMMSS}.csv`
**MIME type**: `text/csv`
**Encoding**: UTF-8 with BOM (for Excel compatibility)
**Format**: RFC 4180 compliant; comma-separated; all fields quoted

### Single-game CSV structure

**Header row**: Always the first row. Column names are human-readable.

```csv
"Export Date","Sport","Game Date","Home Team","Away Team","Final Score Home","Final Score Away","Duration (s)","Format","Tracking Mode","Notes"
"2026-08-08","Baseball","2026-08-07","Wildcats","Eagles","7","4","3240","nine_inning","basic","Great game tonight"
```

### Multi-game CSV structure

One header row, one data row per game:
```csv
"Export Date","Sport","Game Date","Home Team","Away Team","Final Score Home","Final Score Away","Duration (s)","Format","Tracking Mode","Notes"
"2026-08-08","Baseball","2026-08-07","Wildcats","Eagles","7","4","3240","nine_inning","basic",""
"2026-08-08","Basketball","2026-08-06","Lakers","Celtics","88","82","5400","full","basic","Overtime game"
```

### Extended columns (in-depth mode games)

When `tracking_mode == 'in_depth'`, additional columns are appended:
```
"Player Stats JSON"
"{\"home\":{\"players\":[{\"name\":\"Smith\",\"stats\":{\"points\":22,...}},...]},...}"
```

> The Player Stats JSON column contains a single JSON string for full player data. This is intentionally a single embedded JSON column rather than exploding all player stats into dozens of columns — more portable for re-import.

## JSON Export

**File naming**: `SkorKeeper_Export_{YYYYMMDD_HHMMSS}.json`
**MIME type**: `application/json`
**Format**: Pretty-printed JSON (2-space indent) using `JsonEncoder.withIndent('  ')`

### Schema

```json
{
  "exportVersion": "1.0",
  "exportedAt": "2026-08-08T16:30:00Z",
  "exportedBy": "SkorKeeper",
  "games": [
    {
      "id": 42,
      "sport": "baseball",
      "gameFormat": "nine_inning",
      "trackingMode": "basic",
      "startedAt": "2026-08-07T19:00:00Z",
      "endedAt": "2026-08-07T20:54:00Z",
      "durationSeconds": 3240,
      "homeTeam": {
        "id": "home",
        "name": "Wildcats",
        "finalScore": 7,
        "stats": {
          "hits": 10,
          "errors": 1,
          "strikeouts": 8,
          "walks": 3,
          "earnedRuns": 7,
          "inningScores": [0, 2, 0, 1, 0, 3, 0, 0, 1]
        },
        "roster": null
      },
      "awayTeam": {
        "id": "away",
        "name": "Eagles",
        "finalScore": 4,
        "stats": { ... },
        "roster": null
      },
      "events": [
        {
          "id": "sport_baseball_1723060800000",
          "gameTimeSeconds": 0,
          "wallClockMs": 1723060800000,
          "eventType": "hit",
          "teamId": "home",
          "playerId": null,
          "pointsDelta": 0,
          "metadata": null
        }
      ],
      "notes": "Great game tonight",
      "winner": "Wildcats"
    }
  ]
}
```

### In-depth mode JSON additions

When `trackingMode == "in_depth"`, the `homeTeam` and `awayTeam` objects include a `roster` array:

```json
"roster": [
  {
    "id": "player_uuid_001",
    "name": "Smith",
    "number": "23",
    "stats": {
      "points": 22,
      "rebounds": 8,
      "assists": 5,
      "steals": 2,
      "blocks": 1,
      "fouls": 3
    }
  }
]
```

### JSON Schema versioning

The `exportVersion` field allows future schema changes. Version `"1.0"` is the initial contract. Importers should check this field.

## Export Error Handling

| Error | User-Facing Message |
|---|---|
| `path_provider` temp dir unavailable | "Unable to create export file. Please check device storage and try again." |
| PDF generation error | "Export failed. Please try again." |
| `share_plus` cancelled by user | Silent — no error shown |
| No games selected for export | "Please select at least one game to export." |
| Game data missing/corrupt | That game is skipped; a warning is shown: "1 game could not be exported due to missing data." |
