# Updates Screen Notes

The Settings screen includes a **What's New** entry that opens an updates page.

That page shows:
- version numbers
- release dates
- a short bullet list of features, improvements, and fixes for each release

Future speckit additions that add user-visible functionality should also add a matching entry to this file so the in-app updates page can stay aligned with the spec history.

---

## Version 2.0.0 — SkorKeeper Pro

**Release date**: 2026-08-07

### 🎉 Introducing SkorKeeper Pro

- **SkorKeeper Pro** — upgrade once, own forever ($3.99). Removes all ads and unlocks every Pro feature permanently. Restore your purchase anytime from Settings.

### 🎨 Themes

- **8 color themes** — choose a new look for the entire app. Midnight Wolves is free for everyone. Seven Pro themes unlock with SkorKeeper Pro:
  - Purple Reign — deep royal violet, light and dark.
  - Sunset Blitz — warm amber and coral.
  - Arctic Fox — clean cool whites and icy blue.
  - Neon Jungle — vivid greens and electric accents.
  - Royal Crimson — deep red and gold.
  - Ocean Deep — rich navy and teal.
  - Golden Hour 🏆 — warm gold and rich brown.
- **Theme preview** — tap any theme card in the Theme Picker to see a live preview applied to the entire app before committing.
- **Themed dice** — the dice roller now uses your active theme's color palette.

### 🔊 Sound Packs

- **8 sound packs** — Classic is free; seven Pro packs unlock with SkorKeeper Pro: Arcade, Nature, Jazz, Minimal, Epic, Neon, and Sports.
- Sound is now audible throughout the app — fixed an issue where sounds were not playing.

### 📊 History

- **Unlimited history** — Pro users keep every game session forever. Free users retain the 20 most recent sessions.
- **CSV export** — Pro users can export history to a spreadsheet. Choose to export all games or filter by game type. The file is shared via the system share sheet — no account needed.
- **Sort controls** — sort your history by date (newest or oldest first), game type, or session duration.

### 🎨 Personalization

- **Default player colors** — set default colors for each player seat in Settings. Your choices carry forward automatically when you start a new game.

### 💛 Tip Jar

- **Support the developer** — if you love SkorKeeper and want to say thanks, the Tip Jar is in Settings → Support the Developer. Three optional tiers: $0.99, $2.99, or $4.99. No features are gated — this is purely gratitude.

### 📖 FAQ & Settings

- **FAQ** is now its own screen with organized sections for easier navigation.
- **Pro Active** tile in Settings — tap it to see a full list of everything your Pro upgrade includes.

### 🔧 Fixes

- Fixed Purple Reign theme: radio button selected-item backgrounds are now readable in both light and dark mode.
